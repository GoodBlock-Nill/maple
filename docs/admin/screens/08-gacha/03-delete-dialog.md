# 가이드 — 삭제 다이얼로그 (`/gacha` 행 조치)

**목적** 목록 행의 `삭제` 버튼이 여는 확인 다이얼로그(`DeleteGachaButton`). 확률형 아이템은 공시 자료라 소프트 삭제가 아니다 — 행이 실제로 지워지고 되돌릴 수 없다. 그래서 한 단계를 세워 목록에서의 오조작을 막는다.

**데이터 출처** 별도 조회가 없다. 목록 행의 `id`·`name` 만 받아 그린다. 실제 존재 확인은 서버 액션이 삭제 직전 `select('*').eq('id', id).maybeSingle()` 로 한다.

## 1.1 다이얼로그

| 필드/컨트롤 | 종류 | 필수·제한 | 기본값 | 동작 |
|---|---|---|---|---|
| 삭제(행) | 버튼(danger, sm) | write 권한자에게만 | — | 다이얼로그를 연다 |
| 제목 | 고정 문구 | — | `아이템 삭제` | — |
| 설명 | 고정 문구 | — | 아래 상세 참고 | 대안을 함께 알린다 |
| id | hidden | 빈 값이면 즉시 거절 | 행의 `id` | — |
| 오류 배너 | `FormBanner` | — | 없음 | `formError` 표시 |
| 취소 | 버튼(secondary) | 처리 중 비활성 | — | 다이얼로그만 닫는다 |
| 삭제 | 제출 버튼(danger) | 처리 중 비활성 | — | `deleteGachaItemAction` |

**동작 상세**

- **설명** 문구는 `{이름}을(를) 삭제합니다. 되돌릴 수 없습니다. 잠시 내리려는 것이라면 발행을 해제해 주세요.` 다. 조사는 `josa()` 가 이름 끝 받침으로 결정한다.
- **설명** 되돌릴 수 있는 대안(공개 해제)을 같은 문장에서 알린다.
- **오류 배너** 실패해도 다이얼로그는 닫히지 않는다.
- **삭제** 처리 중에는 `삭제 중…` 으로 바뀐다.

## 1.2 서버 동작 (`deleteGachaItemAction`)

| 단계 | 내용 |
|---|---|
| 권한 | `requirePermission('gacha','write')` |
| 검증 | zod 없음. `id === ''` 이면 거절 |
| 선조회 | `gacha_items` 행 전체를 `before` 로 읽는다 |
| DB | `delete().eq('id', id)` — 하드 삭제 |
| 감사 | `gacha.delete` |
| 캐시 | `revalidatePath('/gacha')` + `revalidateClient(['gacha'])` |
| 성공 | 토스트 + 다이얼로그 닫힘 |

**동작 상세**

- **권한** UI 를 거치지 않는 직접 POST 도 여기서 막힌다.
- **DB** `deleted_at` 같은 소프트 삭제 컬럼이 테이블에 없다.
- **감사** `target_table='gacha_items'`, `target_id=id`, `before` 는 지워진 행 전체다. 복구가 필요하면 이 값을 읽어 다시 등록해야 한다.
- **성공** 토스트 문구는 `{이름}을(를) 삭제했습니다.` 이고, 목록은 `revalidatePath` 로 다시 그려진다.

**클라이언트와의 상호작용**

- 공개 중이던 아이템을 지우면 태그 `gacha` 재검증으로 사용자 사이트 `/guide` 목록과 상세 모달(`?item=<id>`)에서 함께 사라진다.
- 재검증에 실패해도 상세 조회가 `is_published` 와 행 존재를 다시 확인하므로 최대 60초 뒤에는 정리된다.
- 삭제된 아이템의 `?item=<id>` 링크(북마크·공유)는 모달 없이 목록만 보인다(`getGachaItemById` 가 `null`).

**오류·예외**

- `id` 가 비었을 때: "대상을 찾을 수 없습니다."
- 행이 이미 없을 때: "이미 삭제된 항목입니다."
- DB 실패: "확률형 아이템을 삭제하지 못했습니다. 목록을 새로고침한 뒤 다시 시도해 주세요."
- 아이콘으로 올린 Storage 파일은 지우지 않는다. `public-assets/gacha/<uuid>.<ext>` 는 그대로 남고 참조만 사라진다.
- 두 운영자가 같은 행을 동시에 지우면 뒤에 누른 쪽이 "이미 삭제된 항목입니다."를 본다.
- 잠시 내리려는 경우에는 삭제 대신 등록 폼의 `사용자 사이트에 공개` 체크를 해제한다(→ [02-form.md](02-form.md) §1.1).
