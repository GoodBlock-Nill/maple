# 문서 구조 규칙 (2026-09-14 개정)

- 대메뉴마다 **폴더** 하나: `docs/admin/screens/<번호-메뉴>/`
  예) `02-news/`, `07-support/`, `11-legal/`
- 폴더 안에는 **화면 하나당 파일 하나**:
  - `README.md` — 메뉴 개요: `_TEMPLATE.md` 의 "0. 한눈에" 표 + 이 폴더의 화면 목록(파일 링크·경로·한 줄 설명) + 메뉴 전체에 걸친 공통 규칙(권한·상태 전이·캐시 태그)
  - `01-list.md` — 메인(목록) 화면
  - `02-detail.md` — 상세 화면
  - `03-new.md` / `04-edit.md` — 생성·수정 화면(같은 폼이면 `03-form.md` 하나로 두고 생성/수정 차이를 절로 나눈다)
  - 다이얼로그·탭·하위 관리 화면도 각각 파일: 예) `05-templates.md`, `05-templates-edit.md`, `06-resolve-dialog.md`
  - 파일 번호는 사용자가 화면을 만나는 순서(목록 → 상세 → 생성/수정 → 부가)
- 각 화면 파일은 `_TEMPLATE.md` 의 "1. <화면 이름>" 이하 형식(목적 · 데이터 출처 · 섹션별 필드 표 · 상태·뱃지 · 클라이언트 상호작용 · 오류·예외)을 **빠짐없이** 따른다.
- 최상위 `docs/admin/screens/README.md` 는 폴더 색인만 둔다.
- 옛 단일 파일(`NN-menu.md`)은 폴더로 옮긴 뒤 삭제한다.
